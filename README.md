# 꼬마 자동차 마을

아이패드 터치와 컴퓨터 마우스로 즐기는 3D 소방 놀이입니다.

**게임 주소:** https://greenpainter.github.io/number-game/

## 놀이 방법

1. 바닥을 누르면 밝은 버킷햇과 초록색 반바지를 입은 아이가 걸어갑니다.
2. 실제 소방서 건물을 누르면 중앙 셔터가 열리고 소방차가 출차합니다. 아이는 앞에서 기다렸다가 차에 탑승합니다.
3. 처음 소방차에 탑승하면 장작에 불이 납니다. 불을 직접 누르면 출동하고, 도착하면 자동으로 물을 뿌립니다.
4. **내리기**를 누르면 아이가 복귀 경로 밖으로 내립니다. 소방차는 자동으로 소방서에 돌아가 문이 열린 차고로 후진 입고하고 문을 닫습니다. 아이는 계속 걸어 다닐 수 있습니다.
5. 차에 탄 상태에서 소방서 건물을 누르면 돌아가 하차합니다. 진압 후 내렸다가 소방차에 다시 타면 새로운 불이 납니다. 기존 불을 끄다가 내린 경우에는 그 불을 이어서 끕니다.

머리 위 라벨 대신 소방서 건물과 불타는 장작을 직접 누릅니다. 직교 투영 쿼터뷰 카메라는 걷는 아이를 중심으로 따라가며, 탑승 중에는 소방차를 따라갑니다.

아래 안내판 없이 한국어 음성으로 출차, 탑승 후 화재 발생, 출동, 진압, 하차를 안내합니다. 소리는 처음 화면을 누른 뒤 활성화되며 오른쪽 위 스피커 버튼으로 끄거나 켭니다. 한국어 안내 61개는 Supertonic 3 여성 음색 F1으로 미리 생성한 MP3를 재생합니다. 음성은 AI로 생성되었습니다. iPad에서 홈 화면에 추가하면 앱처럼 열 수 있습니다.

## 구성

- 정적 HTML/CSS/JavaScript 및 Three.js 0.180.0. 별도 서버 기능, 로그인, API 키가 필요하지 않습니다.
- Blender로 만든 마을, 소방차, 장작, 관절이 분리된 아이 GLB 모델.
- 소방차 개선 원본과 PNG는 `../games/assets/firetruck-detailed/`, 생성 스크립트는 `../games/tools/blender/build_firetruck_detailed.py`에 있습니다. `games` 폴더에서 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/blender/run.ps1 -Script tools/blender/build_firetruck_detailed.py`로 생성한 뒤 PNG와 `verification.json`을 확인하고 GLB를 이 저장소의 `models/firetruck.glb`로 복사합니다. 새 모델은 53,280개 삼각형, 12개 재질, 약 1.41 MB이며 실제 아이패드 성능은 별도 확인이 필요합니다.
- `game-state.js`: 걷기, 차고 출입, 탑승 후 화재 발생, 운전, 하차, 진압 상태.
- `narration.js`: 녹음 파일 재생, 상황 안내, 음소거, 문장 중간 끊김 방지. 아이패드 터치로 활성화한 AudioContext를 효과음과 공유합니다.
- `navigation.js`: 장애물 및 주차된 소방차를 고려한 이동 경로.
- Three.js 및 로더는 `vendor/`에 포함되며 MIT 라이선스는 `vendor/LICENSE.txt`에 있습니다.
- 원래 숫자 게임의 배포 화면을 교체했습니다. 이전 버전은 Git 이력에 남아 있습니다.

## 로컬 실행과 검사

Node.js 환경에서 저장소 루트를 열고 실행합니다.

```sh
node serve.mjs
```

브라우저에서 http://127.0.0.1:4173/ 에 접속합니다. ES 모듈과 모델 로딩을 위해 파일을 직접 여는 대신 웹 서버를 사용합니다.

```sh
node --check game.js
node --test tests/*.test.mjs
```

자동 테스트는 셔터가 완전히 열린 뒤 출입하는지, 출차 후 탑승, 하차 후 자동 입고, 탑승 취소, 복귀 중 재호출, 진압 중 하차와 재개, 보행과 복귀의 동시 실행을 확인합니다. 브라우저에서 1024×768 및 768×1024 화면을 확인하며, 실제 iPad 기기 검사는 별도입니다.

## 배포

**사용자가 명시적으로 배포를 요청했을 때만 커밋·푸시하여 배포합니다. 로컬 수정과 검증만으로 배포하지 않습니다.**

기존 GitHub Pages의 `main` 브랜치 루트 배포를 사용합니다. 모든 실행 리소스는 상대 경로이며 `.nojekyll`을 포함합니다. `main`에 푸시하면 같은 게임 주소에 반영됩니다.

## 확장판: 덤프트럭 흙 운반

- 마을 서쪽 대형 주차장: 빨강·파랑·초록 버스 3대와 노란 덤프트럭.
- 덤프트럭을 직접 누르면 걸어가 탑승합니다. 빨강·파랑·초록 버스도 직접 눌러 탑승하고 운전할 수 있습니다. 하차하면 자기 주차 칸으로 돌아갑니다.
- 동쪽 모래 공터의 포크레인을 누르면 덤프트럭이 작업 위치로 이동하고, 포크레인이 세 번 퍼서 적재합니다.
- 모래 공터 남쪽 초록색 테두리 하역장을 누르면 이동 후 적재함과 뒤판을 열어 흙을 내립니다. 흙더미가 남으며 여러 번 운반할 수 있습니다.
- 하차하면 아이는 그 자리에 있고 덤프트럭만 원래 주차 칸으로 복귀합니다. 적재 중 하차 시 이미 받은 흙은 유지됩니다.
- 소방차 임무와 독립적으로 동작하며 카메라는 현재 조작 중인 아이 또는 차량을 따라갑니다.
- 검사: `node --test tests/*.test.mjs`.

## 경찰서·병원·아이스크림

- 마을 북쪽 길에 경찰서와 병원. 실제 건물을 누르면 문이 열리고 차량이 나온 뒤 아이가 탑승합니다.
- 경찰차는 임무 없이 자유 순찰하며 사이렌과 빨강·파랑 경광등이 켜집니다. 앰뷸런스도 자유롭게 운전할 수 있습니다. 소리 버튼은 음성과 사이렌을 함께 제어합니다.
- 내리면 각 차량이 자기 건물로 자동 복귀하고 셔터가 닫힙니다.
- 가운데 집 앞 분홍색 아이스크림차를 걸어서 누르면 받아서 카메라를 향해 5.5초간 먹습니다. 먹고 나면 다시 걸을 수 있습니다.
- Blender 원본과 미리보기는 인접 games/assets/village-services, 모델 제작 스크립트는 games/tools/blender/build_services.py에 있습니다.
- 추가 검사: 차고 출입, 순찰, 자동 복귀, 호출 전환, 동시에 다른 차 탑승, 반복 먹기와 취소.

## 직사각형 마을과 버스 운전

- 이전 땅 4개의 겹치는 면적을 제외한 2,898㎡에서 4,347.2㎡로 확장(약 1.5배). 가로 76m, 세로 57.2m의 직사각형입니다. `models/world-layout.json`에 계산 근거를 저장합니다.
- 중앙 도로와 남쪽 순환도로, 북쪽 공공시설 길을 연결했습니다. 도로에 겹치던 나무·벤치·가로등·흙더미 위치도 정리했습니다.
- 긴 버스는 넉넉한 이동 여유 공간을 사용하며, 세 색상 각각 운전·자동 복귀·재탑승이 됩니다.
- 덤프트럭과 버스는 낮고 일정한 엔진음을 사용합니다. 사이렌은 경찰차와 앰뷸런스에만 사용하고, 안내 음성이 나올 때는 작아집니다.
- 한국어 안내는 무료 로컬 도구 Supertonic 3의 F1 음색으로 생성한 음성 파일을 사용합니다. 음성 API와 키는 필요하지 않습니다. 문장을 끝낸 뒤 최신 안내를 이어서 재생하며, 음소거 또는 화면을 벗어나면 대기 중 안내도 취소합니다. 생성 방법과 라이선스는 [audio/ko/README.md](audio/ko/README.md)에 있습니다.
- 경찰차와 앰뷸런스의 창문은 차체 평면 안에 맞추고 돌출 두께를 줄였습니다.
- 제작 원본: 인접 games/assets/rectangular-village, games/tools/blender/build_rect_village.py.


## 터치 조작 개선과 낚시터

- 길게 누르거나 조금 끌려도 닿는 순간 한 번 반응합니다. 다른 손가락이 기존 입력을 취소하지 않으며, 펜 사용 중 넓은 손바닥 접촉을 걸러냅니다. 텍스트 선택·이미지 드래그·길게 눌러 메뉴 열기를 막았습니다.
- 작은 대상은 주변 터치도 받아들이고, 빈 곳을 누르면 가까운 이동 가능한 지점으로 보정합니다. 같은 차를 반복해서 눌러도 탑승을 다시 시작하지 않습니다.
- 아이스크림을 먹는 동안 1.38배로 부드럽게 확대하고 식사가 끝나면 복귀합니다.
- 버스 주변에 하차 여유가 없으면 가까운 안전 지점으로 움직여 내린 뒤 원래 주차장으로 돌아갑니다.
- 걷기와 모든 차량의 주행·자동 복귀 속도를 기존 대비 1.2배 적용했습니다. 문 열기와 놀이 시간은 그대로입니다.
- 도로 폭을 1.5배 넓히고 나무·가로등·집·아이스크림차 위치를 정리했습니다. 경찰서와 병원 테두리의 겹친 면을 제거했습니다.
- 연못의 물이나 나무 낚시터를 누르면 걸어가 3.5초 동안 낚시한 뒤, 잡은 물고기를 번쩍 들고 3초 동안 기뻐합니다. 같은 F1 목소리로 안내하며 반복해서 즐길 수 있습니다.
- 모델 제작 원본: 인접 `games/assets/wide-roads`, `games/assets/wide-road-services`; 제작 스크립트 `games/tools/blender/build_play_update.py`.
- 자동 테스트와 데스크톱 브라우저 동작 확인을 했습니다. 실제 Apple Pencil/iPad 하드웨어 검사는 별도입니다.

## 기차 마을과 동물 친구

- 기존 4,347.2㎡에서 17,388.8㎡로 면적 4배 확장했습니다. 가로 152m, 세로 114.4m이며 외곽 도로와 주택가를 추가했습니다.
- 동서남북 네 승강장 또는 기차를 누르면 걸어가서 탑승합니다. 기차가 다른 정류장에 있으면 선택한 승강장으로 옵니다. 기관차와 객차 2량은 약 425m 순환 철로를 한 방향으로 달립니다. 바닥을 눌러도 철로를 벗어나지 않습니다.
- 기차는 북쪽 → 서쪽 → 남쪽 → 동쪽 순서로 다음 승강장에 도착하면 감속·정차한 뒤 자동 하차합니다. 기차는 그 자리에 기다리며 다시 탈 수 있습니다.
- 새 승강장에는 금속 지붕, 목재 벤치, 석재 포장과 보행 건널목이 있습니다. Blender 원본·GLB·PNG 및 재가져오기 검증은 `../games/assets/railway-four-stops/`, 생성 스크립트는 `../games/tools/blender/build_railway_stops.py`에 보관합니다.
- 왼쪽 위 집 아이콘을 누르면 이동·승차·놀이 도중에도 초기화됩니다. 아이, 차량, 기차, 동물, 임무와 카메라가 처음 상태로 돌아옵니다.
- 시작 위치 근처 강아지와 고양이를 누르면 하트로 반응하고 아이를 따라 걷습니다. 장애물을 돌아가며 차를 타는 동안 기다리고, 내리면 다시 따라옵니다.
- `railway-layout.js`가 월드 경계, 배치와 철로의 공통 원본입니다. `railway-state.js`는 열차 운행, `pets-state.js`는 동물 산책, `railway.js`는 모델 표시를 담당합니다.
- Blender 원본·GLB·PNG는 인접 `games/assets/railway-village/`, 재생성 스크립트는 `games/tools/blender/build_railway_village.py`에 있습니다. 내보내기 후 GLB 재가져오기를 검사합니다.
- 경로 탐색은 필요한 격자만 검사하며 우선순위 큐를 사용합니다. 넓어진 전체 지도를 터치마다 모두 순회하지 않습니다.

## 마을 모델 개선

- 주택 18채와 기차역 건물에 기와 결, 처마·홈통, 창틀·창살, 창가 화분, 현관과 석재 기단을 추가했습니다. 소방서·경찰서·병원에는 창문과 지붕 마감을 보강했습니다.
- 기존 도로 배치를 연결된 아스팔트 메시로 다시 만들고 반복 가능한 미세 표면 텍스처, 보도 블록, 낮은 연석, 교차로에서 끊기는 차선과 횡단보도를 추가했습니다. 차고·주차장·작업장 진입부는 열어 두었습니다.
- 기존 월드 경계, 충돌 정보와 이동 경로는 그대로 사용합니다. 차고 문과 하역장의 오브젝트 이름도 보존합니다. 재질 색과 노출·조명을 함께 조정했습니다.
- 편집 가능한 `.blend`, `.glb`, PNG와 검증 보고서: `../games/assets/village-detailed/`. 개선 전 모델은 해당 폴더의 `source-inputs/`에 보관합니다.
- 제작: `games` 폴더에서 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/blender/run.ps1 -Script tools/blender/build_village_detailed.py`. 결과 확인 후 일곱 개 개별 GLB만 이 저장소의 `models/`에 복사합니다. 생성 스크립트는 게임 파일을 직접 덮어쓰지 않습니다.
- 실제 iPad의 프레임 속도와 메모리 사용량은 기기에서 별도 확인이 필요합니다.

## 반복 클릭 성능

- 고밀도 모델은 `picking.js`의 삼각형 공간 분할을 한 번 생성해 클릭 판정에 재사용합니다. 화면 모델은 그대로 유지하고 Three.js의 정확한 면·거리·UV 판정을 보존합니다.
- 같은 지점의 160ms 이내 중복 입력을 합치며 다른 지점을 누르면 즉시 처리합니다. 경로 탐색은 정적 장애물 격자를 재사용하고 선분 충돌을 직접 계산합니다.
- `node --test tests/*.test.mjs`는 실제 GLB의 기존/최적화 클릭 결과 일치, 반복 입력, 네 정류장 운행과 기존 놀이 흐름을 검사합니다. 출력되는 클릭 벤치마크는 21개 광선의 CPU 판정 시간이며 화면 FPS 측정값은 아닙니다.

## 확장 도시

- 월드를 304 × 228.8m, 69,555.2㎡로 늘렸습니다. 직전 마을 면적의 4배이며 기존 마을과 철도는 중앙에 유지합니다.
- 공항과 탑승 가능한 비행기: 공항/비행기를 누르면 걸어가 탑승하고 도시를 돌아 자동 착륙·하차합니다.
- 북쪽 산 터널: 바위 벽·천장 안쪽·벽등을 유지하고 카메라 쪽 외피만 열어 내부가 보입니다. 진입 시 낮은 카메라와 어두운 주변광, 따뜻한 조명으로 전환합니다.
- 서부·동부 소방서를 추가해 총 세 곳입니다. 각 차고의 소방차를 타고 기존 화재에 출동하고, 내리면 자기 차고로 복귀합니다.
- 경찰차 순찰 중 도둑과 만나면 안내가 나오며, 도둑을 누르면 추격하여 가까이에서 검거합니다. 바닥을 누르면 추격을 취소합니다.
- 동물원에 코끼리·기린·얼룩말·사자를 배치했습니다. 차에서 내려 동물을 누르면 관람 길로 이동합니다.
- 주차 차량 7대, 도로를 순환하는 차량 12대, 산책하는 시민 9명을 추가했습니다. 일반 차량은 플레이어가 가까이 오면 대기합니다.
- 왼쪽 위 지도 버튼에서 공항·동물원·터널·소방서 등 목적지를 선택해 이동할 수 있습니다. 신규 놀이 안내는 화면 자막을 사용합니다.
- 주차장의 버스 세 칸에 색상·번호를 맞추고, 덤프트럭을 통행로 밖 전용 구획으로 옮겼습니다.
- 배치: `city-layout.js`; 놀이/교통: `city-state.js`; 모델 표시: `city.js`. Blender 원본, GLB, PNG, 재가져오기 보고서는 `../games/assets/city-expansion/`과 `../games/assets/parking-detailed/`에 있습니다.
- 게임에 설치된 정적 모델만 사용하며 새 외부 라이브러리나 네트워크 서비스는 필요하지 않습니다. 실제 iPad 기기 성능은 아직 측정하지 않았습니다.

## 도로·교통 모델 정비

- 이 단계의 월드는 340 × 228.8m, 77,792㎡이며 이후 확장 내역은 아래에 있습니다.
- 외곽 순환도로 네 모서리에 반경 18m 커브를 넣고, 동쪽에는 지상 도로 위를 가로지르는 곡선 고가도로를 연결했습니다. 고가도로를 누르면 입구까지 이동한 뒤 걸어서 또는 타고 있는 차로 다리를 건넙니다. 주변 자동차도 다리 높이에 맞춰 운행합니다.
- 지도 목적지는 헬기 호출로 이동합니다. 하강, 탑승, 상승, 비행, 착륙, 하차, 이륙 순서로 진행되며 지상 차량에서 안전하게 내린 뒤 탑승합니다. 비행기·기차 이동 또는 다른 잠긴 놀이 도중에는 호출하지 않습니다. 반복 호출은 진행 중인 목적지를 바꾸지 않습니다.
- 비행기의 동체·후퇴익·꼬리날개·조종석·엔진 흡입구를 다시 만들고, 일반 승용차와 경찰차에 경사진 유리·차체 마감·휠·조명을 적용했습니다.
- 공항 활주로/앞마당/연결로는 서로 겹치지 않는 면으로 분할합니다. 얇은 바닥 면은 그림자를 받되 자체 그림자를 투사하지 않아 가장자리 줄무늬를 줄입니다. 새 보도에는 공유 타일 텍스처를 사용하며 기존 도로 텍스처의 차선과 UV는 유지합니다.
- 공통 곡선: `road-layout.js`, 배치: `city-layout.js`, 표면: `surfaces.js`. Blender 제작 원본·GLB·미리보기·검증 보고서: `../games/assets/city-refined/`. 재생성은 `../games/tools/blender/build_city_refined.py`; 기존 `city-expansion` 자산은 수정 전 자료로 보존합니다.
- `node --test tests/*.test.mjs`: 기존 놀이 및 헬기 탑승/착륙/초기화, 버스·경찰차 환승, 고가도로 높이/통과/접근 취소를 검사합니다.

## 숲마을·정원마을과 동물원 확장

- 이 단계의 월드는 490 × 358m, 175,420㎡로 직전 면적의 약 2.25배입니다. 북쪽 숲길과 남쪽 전망길, 정원 연결길을 곡선으로 만들고 기존 도로와 겹치는 면을 제거했습니다. 지도에서 두 새 마을로 헬기를 호출할 수 있습니다.
- 곡선을 향해 배치한 새 집 68채는 코티지, 빌라, 타운하우스, 현대식 주택, 샬레, 소형 아파트 6종입니다. 고가도로는 동쪽 새 주거 도로까지 연결되며 보행·차량 모두 건널 수 있습니다. 주변 차량 21대, 보행자 12명이 움직입니다.
- 동물원은 32 × 28m 공간 12개에 코끼리·기린·얼룩말·사자·판다·펭귄·하마·코뿔소·곰·홍학·캥거루·육지거북을 가족 단위로 총 36마리 배치했습니다. 같은 종은 모델을 공유하며 각각 독립적으로 움직입니다.
- 코끼리 주변 울타리나 바닥을 눌러도 입구로 돌아가던 클릭 판정을 수정했습니다. 우리·안내판은 해당 동물의 관람 지점으로 이동하고, 산책로는 누른 좌표로 이동합니다. 도착하면 동물을 바라봅니다.
- 세 소방차 모두 사이렌을 내고, 헬기는 하강부터 떠날 때까지 회전음이 납니다. 검거 시 F1 한국어 녹음 “잡았다! 도둑을 잡았어요!”를 한 번 재생합니다. 음소거·지도/도움말 일시정지·숨긴 탭에서는 효과음이 꺼집니다.
- 장거리 경로는 4m 격자로 먼저 탐색하고 모든 구간을 실제 장애물과 검사합니다. 좁은 길은 기존 0.5m 격자로 다시 탐색합니다. 동물원 전체 경로의 충돌 여부와 반복 클릭, 실제 GLB 울타리 클릭, 주택 높이를 자동 검사합니다.
- 현재 Blender 원본·GLB·PNG·재가져오기 검증은 `../games/assets/city-neighborhoods/`에 있습니다. 제작 스크립트는 `../games/tools/blender/build_city_neighborhoods.py`, 전체 미리보기는 `preview_neighborhoods.py`, 녹음 생성은 `../games/tools/tts/add_capture.py`입니다. 이전 제작물은 각 기존 폴더에 보존합니다.

## 배치 겹침과 지하철 동선 수정

- 중앙마을역 입구를 주택 사이 여유 공간으로 옮겼습니다. 철도 주변 집 14채는 현관이 마을 도로를 향하며 남쪽 연결로 옆 두 집은 도로 밖으로 이동했습니다. 충돌 영역도 회전한 집과 일치합니다.
- 중앙 도로와 외곽 연결로의 겹친 아스팔트를 제거하고 재질·높이를 통일했습니다. 교차로에 남은 작은 잔디 섬 여섯 곳을 정리했으며, 연결로를 가로지르던 보도와 연석을 열었습니다.
- 지하철은 57개 계단과 중간 계단참을 걸어서 내려간 뒤 승강장을 따라 이동합니다. 문이 열리면 탑승하고 도착역에서는 하차·승강장 보행·계단 오르기를 거쳐 지상으로 돌아옵니다. 열차 정차 위치를 계단 너머에 두어 통로가 겹치지 않습니다. 공통 동선은 `metro-path.js`에 있습니다.
- 집·지도·지하철 버튼을 한 내비게이션으로 묶었습니다. 좁은 화면에서는 오른쪽 소리/도움말 버튼을 다음 줄로 보내며 320·375·768px 화면에서 버튼 간격을 확인했습니다.
- 제작 순서: 기존 구역 생성 후 `../games/tools/repair_town_layout.mjs`, `../games/tools/blender/repair_town_connections.py`, `../games/tools/blender/build_metro_stairway.py`. 편집용 Blender 원본·GLB·PNG·재가져오기 보고서는 `../games/assets/town-connections/`, `../games/assets/metro-stairway/`에 있습니다. 기존 생성기를 다시 실행했다면 이 보정 단계도 적용해야 합니다.

## 탐험 지도와 킥보드

- 지도는 실제 배치 데이터에서 강·세 다리·곡선 도로·고가도로·주택·동물원·공항·지하철역을 그립니다. 내 위치, 14개 목적지 핀, 장소 종류 필터를 지원합니다. 핀이나 목록에서 장소를 고르고 아래의 헬기 버튼으로 출발합니다. 작은 화면에서는 목록을 지도 아래에 표시합니다.
- 상단 🛴 버튼으로 킥보드를 타고 내립니다. 바닥을 누르면 기존 보행 경로를 따라 약 2.6배 빠르게 이동합니다. 탑승 자세·발 구르기 동작·한국어 승하차 안내를 추가했으며 다른 놀이 시작 시 접힙니다. 벽과 강을 통과하지 않고 초기화 시 해제됩니다.
- 강 다리 여섯 받침 기둥은 해당 경사면의 가장 낮은 높이 아래에 맞췄습니다. 고정 높이 기둥이 도로 위로 솟던 현상을 수정했고 실제 GLB를 광선으로 검사합니다.
- 지도: `city-map.js`, `city-map.css`. 킥보드 원본·GLB·PNG·녹음: `../games/assets/town-scooter/`; 기둥 수정 원본: `../games/assets/river-bridge-repair/`. 제작 스크립트: `build_scooter.py`, `repair_bridge_piers.py` 및 `../games/tools/tts/add_scooter.py`. 기둥 보정은 `build_waterfront.py`에도 반영했습니다. 지하철 자산을 유지하려면 강변 지형만 만드는 `repair_bridge_piers.py`를 실행합니다.

## 도로 개편 · 가족 산책 · 순환 지하철

- 중앙 도로는 `town-roads.js`의 중심선으로 다시 만들었습니다. 가까이 평행하던 세 구간을 없애고 교차로·보도를 둥글게 연결했습니다. 단일 노면 메시로 중복 면과 불필요한 그리기 호출을 줄였습니다. 집 지붕은 겹치는 얇은 타일 메시 대신 UV 타일 재질을 사용합니다.
- 동물 12종의 곡면, 눈 위치, 얼룩말·기린·거북 무늬와 귀·발·갈기·목선을 개선했습니다. 기존 36마리의 위치와 클릭 동선은 유지합니다.
- 엄마·아빠 얼굴 버튼은 각각 독립적으로 동행을 켜고 끕니다. 둘 다 켜면 아이 양손을 잡습니다. 좁은 공간에서는 뒤로 따라오고, 다른 탈것을 타는 동안 동행 모델을 숨겼다가 하차 후 다시 합류합니다. 사진의 회색 상의·안경과 검정 상의·가방을 참고한 새 캐릭터입니다.
- 킥보드는 무릎·발목 관절을 이용해 오른발로 바닥을 밀고 발을 회수합니다. 왼발은 발판에 고정되며, 멈추면 발 구르기도 멈춥니다.
- 지하철 상단 버튼과 글자 선택창을 제거했습니다. 역 입구를 누르면 계단과 승강장을 거쳐 다음 역으로 갑니다. 중앙마을 → 공항 → 강변공원 → 동물원 → 중앙마을 순환입니다. 지도에 있는 역 그림으로 목적지를 선택하면 가까운 역에서 타고 순환 방향으로 중간 역을 거쳐 도착합니다.
